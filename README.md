# Business Owner Cockpit для Битрикс24

Статическое приложение-панель собственника: авторизация через Bitrix24 JS SDK, демо-режим вне портала и набор ключевых бизнес-метрик.

## Что показывает

- Финансы: выручка, маржа, EBITDA, денежный остаток, дебиторка.
- Продажи и маркетинг: лиды, конверсия, средний чек, повторные продажи.
- Операции: SLA задач, загрузка команды, воронка по направлениям.
- Контроль собственника: риски и приоритеты на неделю.

## Интеграция с Битрикс24

`index.html` подключает Bitrix24 JS SDK по адресу `https://api.bitrix24.com/api/v1/`. Если приложение открыто внутри портала, оно вызывает `BX24.init()`, определяет домен портала и подготавливает `BX24.callBatch()` для чтения профиля и сделок CRM.

Для продакшена замените демо-агрегацию на серверный API-слой, который безопасно хранит секреты и проксирует обращения к Вайбкод/Битрикс24. Не публикуйте API-ключи в браузерном коде.

## Деплой на Вайбкод

1. Создайте проект статического сайта в Вайбкод.
2. Укажите корневой файл `index.html`.
3. Добавьте API-ключ Вайбкод в секреты окружения проекта, а не в репозиторий.
4. Подключите опубликованный URL как приложение/встраивание в Битрикс24.

## Локальная проверка

Откройте `index.html` в браузере или отдайте папку любым статическим сервером:

```bash
python3 -m http.server 8080
```
