# Asemzhihaz Vision

Мобильный web-прототип приложения для Asemzhihaz: пользователь загружает фото комнаты или коммерческого объекта, а интерфейс показывает AI-анализ пространства и рекомендует подходящие мебельные стили из каталога.

## Возможности прототипа

- Адаптивный мобильный landing/app-интерфейс на одном `index.html`.
- Загрузка фотографии объекта с локальным предпросмотром без отправки файла на сервер.
- Демонстрация AI-подбора: стиль, цветовая палитра, материалы, процент совпадения.
- Карточки дизайн-направлений Asemzhihaz с ориентировочными ценами.
- Клиентский путь: скан объекта → рекомендация → каталог → заявка дизайнеру.

## Как развивать до production

1. Подключить мобильный shell: PWA, Capacitor или React Native WebView.
2. Добавить backend для безопасной загрузки фото и хранения заявок.
3. Интегрировать CV/AI-модель для сегментации комнаты, определения габаритов и генерации рекомендаций.
4. Связать рекомендации с реальным каталогом Asemzhihaz, складскими остатками и CRM.
5. Добавить роли дизайнера и менеджера для ручной корректировки подборок.

## Локальная проверка

Откройте `index.html` в браузере или запустите статический сервер:

```bash
python3 -m http.server 8080
```
