# Business Owner Cockpit для Битрикс24

Статическое приложение-панель собственника: авторизация через Bitrix24 JS SDK, демо-режим вне портала и набор ключевых бизнес-метрик.

## Что показывает

- Финансы: выручка, маржа, EBITDA, денежный остаток, дебиторка.
- Продажи и маркетинг: лиды, конверсия, средний чек, повторные продажи.
- Операции: SLA задач, загрузка команды, воронка по направлениям.
- Контроль собственника: риски и приоритеты на неделю.

## Интеграция с Битрикс24

`index.html` подключает Bitrix24 JS SDK по адресу `https://api.bitrix24.com/api/v1/`. Если приложение открыто внутри портала, оно вызывает `BX24.init()`, определяет домен портала и подготавливает `BX24.callBatch()` для чтения профиля и сделок CRM.

Для продакшена замените демо-агрегацию на серверный API-слой, который безопасно хранит секреты и проксирует обращения к Вайбкод/Битрикс24. Не публикуйте API-ключи в браузерном коде.

## Деплой на Вайбкод

Автоматический деплой подготовлен в `scripts/deploy-vibecode.sh`. Скрипт создаёт Black Hole сервер/приложение, упаковывает `index.html` и `README.md`, ждёт готовности туннеля и запускает Deploy API.

```bash
read -s VIBE_API_KEY && export VIBE_API_KEY
./scripts/deploy-vibecode.sh
```

По умолчанию используются:

- `APP_NAME=business-owner-cockpit`
- `DISPLAY_NAME=Business Owner Cockpit`
- `PLAN=bc-small`
- `REGION=ru-central1-b`
- `RUNTIME=static`

После успешного выполнения скрипт напечатает `APP_URL` вида `https://app-xxxx.vibecode.bitrix24.tech`. Этот URL нужно указать как адрес приложения/встраивания в Битрикс24 или использовать при публикации OAuth-приложения.

Если запускаете деплой вручную через кабинет Вайбкод: создайте проект статического сайта, укажите корневой файл `index.html`, добавьте API-ключ в секреты окружения проекта и подключите опубликованный URL как приложение/встраивание в Битрикс24.

## Локальная проверка

Откройте `index.html` в браузере или отдайте папку любым статическим сервером:

```bash
python3 -m http.server 8080
```
